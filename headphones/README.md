
# Headphones Landing Page

A fully responsive headphones landing page built as part of the **alx_html_css** repository. This project focuses on clean layout structure, mobile responsiveness, and consistent styling.

---

## 📌 Project Overview

This webpage showcases a modern landing page design for a headphones brand. It uses HTML and CSS only, emphasizing responsive design and simple yet polished UI interactions.

The project requirements included:

* A maximum content width of **1000px**, centered on the page.
* A **mobile version** that activates at **480px** screen width or below.
* Link hover/active states using the color **#FF6565**.
* Button hover/active states using **opacity: 0.9**.

---

## 🧩 Features

### ✔ Fully Responsive Layout

* Desktop and mobile breakpoints.
* Mobile layout automatically activates at **≤ 480px**.
* Adjusted typography, images, and layout for smaller screens.

### ✔ Clean & Modern Styling

* Maximum content width constrained to **1000px** for better readability.
* Centered container layout.
* Hover and active states for buttons and links.

### ✔ Pure HTML & CSS

* No frameworks.
* Organized file structure.
* External stylesheet for clean structure.

---



## 📱 Responsive Design

The page includes a media query:

```
@media screen and (max-width: 480px) {
  /* Mobile styles */
}
```

This ensures a clean mobile experience with simplified layout and optimized spacing.

1. Clone the repository:

